# Changelog

## 1.1.0

- Target macOS 14+ on native Apple Silicon and 64-bit Intel.
- Restart Rosetta command sessions in native Apple Silicon mode.
- Select architecture-specific Homebrew paths and Python dependency locks.
- Check tool architecture and private Python health before use.
- Preserve invalid runtime environments before rebuilding them.
- Add Stop, Diagnostics and confirmation-based Uninstall commands.
- Refresh existing login configuration after installation and repair.
- Provide customer installation, usage, maintenance and troubleshooting documentation.

This release retains the playlist sync, atomic MP3 publication, history, local control window and optional BPM analysis from the earlier working version.
